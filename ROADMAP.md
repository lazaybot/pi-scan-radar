# Engineering roadmap

## Completed in software

- Deterministic obstacle simulation
- Ray/circle intersection model
- Forward and reverse sweep generation
- Median range filtering
- Adjacent-return clustering
- CSV logging and JSON summary
- Polar plotting utility
- Unit tests independent of Raspberry Pi hardware

## Next hardware iteration

- Assemble and photograph prototype
- Measure servo current and Pi undervoltage behavior
- Record range bias and repeatability data
- Tune pulse limits and settle time from measurements
- Add a printed enclosure and cable strain relief

## Later improvements

- Live browser dashboard over the local network
- Bidirectional scans with backlash comparison
- Occupancy-grid accumulation as the base moves
- Small OLED status display and battery monitor
- Optional second sensor for vertical profiling

The project should not be described as collision avoidance or a security system
without substantially more validation, redundancy, and failure analysis.
